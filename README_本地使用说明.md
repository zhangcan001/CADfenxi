# 工程图纸智能台账识别系统 v1.2.1-fast-integrity 本地使用说明

## 一、这是什么软件

用于个人本地识别工程 PDF / DXF 图纸，辅助生成图纸台账。
DWG 文件需要先通过外部工具转换为 DXF，再进入识别流程。

## 二、运行环境

- Windows 10 / Windows 11
- Python 3.11+
- 首次安装依赖需要联网
- 不需要单独启动前端
- 不需要数据库服务器
- 默认使用本地 SQLite
- 不内置 DWG 转换工具

## 三、首次使用

第一步：双击 `check_env.bat`。
第二步：双击 `scripts\install_backend_deps.bat`。
第三步：双击 `start.bat`。
第四步：浏览器自动打开系统。

## v1.1.6 使用建议

1. 升级前先关闭系统并完整备份 app_data。
2. 打开旧项目后先运行系统健康检查。
3. 对 DXF / DWG 转 DXF 项目，先执行 CAD pipeline，再查看图纸内嵌表格和块统计结果。
4. 表格抽取和块统计用于辅助核对，复杂表格、合并单元格和非常规块名仍需人工复核。
5. 图纸字段确认后再运行跨图一致性校验，重点检查重复图号、版本跳号、专业前缀错位和出图日期异常。
6. 导出 Excel 后检查“图纸表格明细”和“图纸块统计”两个 sheet，再创建项目备份。

## v1.1.5 使用建议

1. DXF 解析成功后会自动尝试抽取表格和统计 INSERT 块，失败不影响原有识别流程。
2. 在图纸详情中查看“图纸内嵌表格”，用于快速核对设备表、材料表、图纸目录和图例。
3. 对已确认图纸运行跨图一致性校验，未确认图纸不会参与校验。
4. 如果表格或块统计为空，先确认 CAD 解析结果是否存在，再人工复核原始图纸。

## v1.1.4 使用建议

1. 上传 DXF 后先执行 CAD 解析。
2. 如图纸包含设备表、材料表或目录表，导出 Excel 后查看“图纸表格明细”sheet。
3. 表格抽取结果仅作辅助整理，复杂表头、嵌套表和合并单元格需要人工确认。

## 四、日常使用

以后只需双击 `start.bat`。

## 五、停止系统

关闭 `start.bat` 启动窗口即可。

## 六、数据保存位置

所有数据保存在 `app_data/`。

包括：

- SQLite 数据库
- PDF / DXF / DWG 原始文件
- DWG 转换后的 DXF
- PDF 预览图
- CAD JSON
- CAD 预览图
- Excel 导出文件
- 项目备份包
- 启动日志
- 临时文件

## 七、PDF 使用流程

1. 新建或打开项目。
2. 上传 PDF 图纸。
3. 执行 PDF 拆页。
4. 查看整页预览和缩略图。
5. 生成标题栏裁剪图。
6. 执行文本提取和标题栏 OCR。
7. 生成候选值。
8. 执行字段融合。
9. 进入校核工作台，检查图号、图名、专业、版本和日期。
10. 人工确认后导出 Excel。

## 八、DXF 使用流程

1. 新建或打开项目。
2. 上传 DXF 图纸。
3. 准备 DXF 图纸页。
4. 解析 DXF，生成 CAD JSON。
5. 生成 CAD 轻量预览。
6. 生成候选值。
7. 执行字段融合。
8. 进入校核工作台人工复核。
9. 导出 Excel。

## 九、DWG 使用流程

DWG 使用说明：

系统不直接解析 DWG。
需要用户自行安装 ODA File Converter 或其他 DWG 转 DXF 工具。
DWG 转换为 DXF 后进入 DXF 识别流程。

推荐流程：

1. 在系统中配置外部 DWG 转 DXF 工具。
2. 上传 DWG 文件。
3. 执行 DWG 转 DXF。
4. 转换成功后准备 DXF 图纸页。
5. 解析 DXF、生成 CAD 预览、生成候选值并校核。
6. 导出 Excel。

## 十、CAD 预览说明

CAD 预览查看操作：

- CAD 预览仅用于辅助查看。
- 支持 DXF 和 DWG 转 DXF 后的预览。
- 支持缩放、拖拽、下载 PNG。
- 支持适应窗口、100% 显示、重置视图和重新生成预览。
- 复杂图形、字体、外部参照可能显示不完整。
- 正式查看仍建议使用专业 CAD 软件。
- 预览失败不影响识别、校核和导出。

CAD 批量预览说明：

1. 进入项目页面。
2. 打开 CAD 批量处理或数据处理区域。
3. 点击批量生成 CAD 预览。
4. 建议勾选跳过已生成预览。
5. 如需刷新图片，可使用强制重新生成。
6. 单张预览失败不影响台账识别和 Excel 导出。

CAD 预览稳定版说明：

DXF 图纸可以生成轻量 CAD 预览；DWG 需要先转换为 DXF，再生成 CAD 预览。复杂图纸、字体缺失、外部参照可能导致预览不完整，正式查看仍建议使用专业 CAD 软件。

## 十一、Excel 导出说明

Excel 导出包含：

- 图纸总台账
- 问题清单
- 专业汇总
- 校核状态汇总
- 导出说明

导出规则：

- 人工确认值优先。
- 导出不会改变图纸状态。
- 导出不会改变问题状态。
- 如存在未校核或低可信图纸，建议在 Excel 中继续重点复核。

## 十二、项目备份与恢复

备份方法：

- 单项目备份适合迁移或恢复单个项目。
- 备份成功后可以下载备份包。
- 恢复项目会创建新项目。
- 恢复不会覆盖原项目。
- 删除备份不会删除项目。
- 删除项目前建议先创建项目备份。

## 十三、app_data 全量备份与迁移

## 数据备份与迁移

迁移方法：

关闭系统后复制整个 `app_data` 目录，即可备份全部项目和记录。

全量 app_data 备份：关闭系统后复制整个 `app_data` 目录。

换电脑迁移：

1. 在旧电脑关闭系统。
2. 复制整个 `app_data/`。
3. 将 `app_data/` 放到新电脑的 portable 包根目录。
4. 运行 `check_env.bat`。
5. 运行 `start.bat`。
6. 检查项目列表、图纸台账和 Excel 导出。

升级 portable 保留数据：

1. 关闭旧系统。
2. 复制整个 `app_data/`。
3. 将旧 `app_data/` 放入新版 portable 包根目录。
4. 启动新版系统检查项目。

不要只复制 `database` 或只复制 `projects`。只复制其中一部分会导致项目列表、图纸文件、预览、CAD JSON 或备份记录不一致。

## 十四、系统维护

- 系统健康检查：检查 app_data、数据库、项目、备份、导出和临时目录状态。
- 项目完整性检查：检查单个项目中的原始文件、预览、CAD JSON、CAD 预览、导出文件等。
- 备份检查：检查备份记录对应的 zip 是否存在。
- 导出检查：检查 Excel 导出记录对应的文件是否存在。
- temp 清理：只清理 `app_data/temp/`。
- 健康检查不会自动修改数据库。
- temp 清理不会删除项目文件、备份文件或导出文件。

## 十五、常见问题

### start.bat 闪退怎么办

遇到 `start.bat` 闪退时，先运行 `check_env.bat`，查看 Python、pip、端口和 app_data 权限是否正常。再查看 `app_data/logs/local_launcher.log`。

### Python 不存在怎么办

安装 Python 3.11+，并在安装时勾选 Add Python to PATH。

### pip 安装失败怎么办

确认网络可用，重新运行 `scripts\install_backend_deps.bat`。如公司网络限制访问外网，需要切换网络或配置 pip 镜像。

### 8000 端口被占用怎么办

关闭旧的 `start.bat` 窗口，或结束占用 8000 端口的本机 Python 进程。

### 页面打不开怎么办

确认 `start.bat` 窗口没有报错，再手动访问 `http://127.0.0.1:8000`。

### 后端未连接怎么办

查看 `app_data/logs/local_launcher.log`，重点检查依赖是否安装、端口是否占用、app_data 是否可写。

### app_data 不可写怎么办

把软件放到有写入权限的目录，例如用户文档目录或 D 盘普通目录，不建议放在系统受保护目录。

### DWG 转换工具未配置怎么办

系统不内置 DWG 转换工具。请安装 ODA File Converter 或其他转换工具，然后在系统中配置转换工具路径。

### CAD 预览失败怎么办

预览失败不影响识别、校核和导出。可尝试重新生成预览，或使用专业 CAD 软件打开原图确认。

### Excel 导出失败怎么办

先运行导出前检查，确认项目中已有图纸页。若仍失败，请查看导出错误提示和日志。

### 项目备份失败怎么办

确认 `app_data/backups/` 可写，确认项目文件没有被其他程序占用，再重新备份。

### 恢复项目失败怎么办

先校验备份包。若缺少 `backup_manifest.json` 或 `database/project_data.json`，请更换有效备份包。

### 项目列表为空怎么办

确认 `app_data/` 是否放在 portable 包根目录。迁移时应复制整个 `app_data/`，不要只复制其中一部分。

### 图纸预览缺失怎么办

PDF 可重新拆页或重新生成预览。CAD 预览可重新生成。预览缺失通常不影响台账数据和 Excel 导出。

### 如何查看 local_launcher.log

打开 `app_data/logs/local_launcher.log`。

### 如何备份数据

关闭系统后复制整个 `app_data/`。重要项目也建议在系统内创建项目备份。

### 如何迁移到新电脑

复制整个 portable 包，或至少复制整个 `app_data/` 到新电脑的新版 portable 包根目录，然后运行 `check_env.bat` 和 `start.bat`。

### 如何升级 portable 包

先备份旧包的 `app_data/`，再放入新版 portable 包根目录，确认项目列表和关键项目可打开后再继续使用。
