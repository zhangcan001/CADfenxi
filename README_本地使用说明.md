# 工程图纸智能台账识别系统 v0.6.2-rule-fix 本地使用说明

## 一、这是什么软件

工程图纸智能台账识别系统用于本地识别 PDF / DXF 图纸，辅助生成图纸台账，并支持外部工具将 DWG 转为 DXF 后继续识别。

所有功能在本机运行，数据默认保存在便携包目录下的 `app_data/`。

## 二、v0.6.2 识别规则小修与低风险优化

v0.6.2 是识别规则小修与低风险优化版本。本版本不新增功能，只针对真实使用中发现的图号、图名、专业、CAD tag、日期和低可信提示问题做小修。

本版建议：

* 用真实小项目复测 PDF / DXF / DWG 转 DXF 后识别闭环。
* 重点抽查图号标准化、说明文字误判、构件编号误判、专业判断和日期字段。
* 对低可信、仅文件名来源、OCR 空文本和日期异常提示，优先进入校核工作台人工确认。
* 本版本不新增 CAD 图形预览、不直接解析 DWG、不改变 Excel 模板结构。

## 三、v0.6.1 稳定版真实使用问题修复

导出建议：

* 导出前先查看导出检查摘要，重点关注未校核、缺图号、缺图名、错误、警告和 D 级图纸。
* 导出的 Excel 包含图纸总台账、问题清单、专业汇总、校核状态汇总和导出说明。
* 有 warning 时仍可导出，但应在 Excel 中重点复核低可信或存在问题的图纸。

## 七、v0.5.2 校核工作台效率优化

v0.5.2 是校核工作台效率优化版本。新增或优化筛选、排序、批量确认、快速采用候选值、字段来源说明、问题聚合展示，目标是减少真实项目台账人工校核时间。

建议校核流程：

* 先用顶部问题统计定位错误、缺图号、缺图名、低可信图纸。
* 使用“低可信 + 未校核”“有错误 + 未校核”“缺图号 + 未校核”等组合筛选优先处理风险图纸。
* 对 A 级、A/B 级或字段完整图纸执行批量确认；系统会自动跳过 open error、缺图号、缺图名和 failed 图纸。
* 在字段校核区查看来源说明和候选值，必要时快速填入候选值、立即采用并保存或恢复机器推荐。
* 使用 Ctrl+S 保存当前修改，Ctrl+Enter 保存并确认。

## 九、运行环境

* Windows 10 / Windows 11
* Python 3.11+
* 首次安装依赖需要联网
* 不需要单独启动前端
* 不内置 DWG 转换工具
* 不需要数据库服务器，默认使用本地 SQLite

## 十、首次使用步骤

第一步：双击环境检查：

```text
check_env.bat
```

第二步：双击安装后端依赖：

```text
scripts\install_backend_deps.bat
```

第三步：双击启动系统：

```text
start.bat
```

第四步：浏览器会自动打开：

```text
http://127.0.0.1:8000
```

## 十一、日常使用

以后只需要双击：

```text
start.bat
```

不需要单独启动前端，前端页面已经由后端托管。

## 十二、停止系统

关闭 `start.bat` 启动窗口即可停止服务。

## 十三、数据保存位置

所有数据保存在：

```text
app_data/
```

包括：

* 项目数据
* SQLite 数据库
* PDF / DXF / DWG 原始文件
* DWG 转换后的 DXF
* CAD 解析 JSON
* Excel 导出文件
* 启动日志

## 十四、备份方法

关闭系统后，复制整个：

```text
app_data/
```

即可备份项目数据。

## 十五、迁移方法

完整迁移：把整个 portable 包复制到新电脑。

只迁移数据：把旧电脑的 `app_data/` 复制到新电脑同名目录。

建议关闭系统后再复制，避免数据库文件正在写入。

## 十六、DWG 使用说明

系统不直接解析 DWG。  
如需处理 DWG，请自行安装 ODA File Converter 或其他 DWG 转 DXF 工具，并在系统中配置路径。  
转换后的 DXF 会继续进入系统已有 DXF 识别流程。

## 十七、常见问题

1. `start.bat` 闪退怎么办。

   先双击 `check_env.bat` 查看环境检查结果。也可以在命令行中进入便携包目录后运行 `start.bat`，窗口会保留错误提示。

2. Python 不存在怎么办。

   请安装 Python 3.11+，安装时勾选 `Add Python to PATH`。安装完成后重新运行 `check_env.bat`。

3. pip 安装失败怎么办。

   确认电脑可以联网，再重新运行 `scripts\install_backend_deps.bat`。如果仍失败，请保留窗口中的错误信息，通常是网络、镜像源或 Python 环境问题。

4. 8000 端口被占用怎么办。

   如果看到 `PORT_8000_IN_USE`，先关闭旧的 `start.bat` 窗口。本系统默认不自动换端口。

   如果仍然提示占用，重启电脑是最简单的办法。

   高级用户可以打开命令行执行：

```text
netstat -ano | findstr :8000
```

   根据 PID 判断是否结束对应进程。普通用户不建议直接强杀不认识的进程。

5. 页面打不开怎么办。

   确认 `start.bat` 窗口仍在运行，然后访问 `http://127.0.0.1:8000`。如果仍打不开，请查看 `app_data/logs/local_launcher.log`。

6. 后端未连接怎么办。

   访问 `http://127.0.0.1:8000/api/health`。如果无法访问，说明后端未启动成功，请查看启动窗口和日志。

7. `app_data` 不可写怎么办。

   请把便携目录放到当前用户有写入权限的位置。

   不要放在以下目录：

```text
C:\Program Files\
C:\Windows\
系统保护目录
无写入权限的网盘同步目录
```

   推荐放在：

```text
D:\工程图纸系统\
D:\DrawingLedger\
桌面普通文件夹
```

8. DWG 转换工具未配置怎么办。

   系统仍可处理 PDF / DXF。若要处理 DWG，请安装外部 DWG 转 DXF 工具，并在系统的 CAD 转换设置中配置路径。

9. 中文路径 / 空格路径启动异常怎么办。

   本版本已验证中文路径和带空格路径。若仍打不开，请把便携包移动到较短路径，例如：

```text
D:\DrawingLedger\
D:\图纸识别系统\
```

   然后重新运行 `check_env.bat`。

10. 如何查看 `local_launcher.log`。

   启动日志在：

```text
app_data/logs/local_launcher.log
```

   后端运行日志在：

```text
app_data/logs/app.log
```

11. 如何备份和恢复数据。

   备份：关闭系统后复制整个 `app_data/`。  
   恢复：把备份的 `app_data/` 放回 portable 包根目录，覆盖同名目录。
