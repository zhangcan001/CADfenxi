# v0.8.1 CAD 预览真实样本兼容性测试报告

## 一、测试环境

| 项目 | 内容 |
|---|---|
| 操作系统 | Windows |
| Python 版本 | Python 3.14.3 |
| Node 版本 | Node v24.14.0 / npm 11.9.0 |
| 测试版本 | v0.8.1-cad-preview-compat |
| 测试日期 | 2026-05-22 |

## 二、样本类型

| 样本 | 结果 | 备注 |
|---|---|---|
| 普通 DXF | 通过 | 自动化测试覆盖 |
| 中文文字 DXF | 通过 | 记录字体 fallback warning |
| 大范围坐标 DXF | 通过 | 自动适配图纸范围 |
| 图形很小或很偏的 DXF | 通过 | bbox 归一化与留边 |
| 多图层 DXF | 通过 | 基础几何渲染 |
| TEXT / MTEXT | 通过 | 尽量显示，不保证字体完全一致 |
| INSERT / BLOCK | 通过 | 不展开复杂块，记录 warning |
| CIRCLE / ARC / POLYLINE | 通过 | 自动化测试覆盖 |
| DWG 转 DXF | 通过 | mock 转换样本覆盖 |
| 损坏 DXF | 通过 | 结构化失败，不影响旧流程 |

## 三、结论

- CAD 预览可作为 v0.8.1 兼容性优化版继续试用。
- 复杂块、XREF、字体完全一致性仍属于后续优化范围。
