# v0.5.1 真实项目识别质量优化计划

## 一、问题来源

- REAL_PROJECT_TRIAL_REPORT_v0.5.md
- REAL_PROJECT_TRIAL_ISSUES_v0.5.md

## 二、质量问题分类

| 类别 | 问题数量 | 典型现象 | 优化策略 |
|---|---:|---|---|
| 图号识别 | 1 | 文件名与 CAD 文本里常见 `建施 01`、`A101`、`JS-01` 等格式需要更稳 | 扩展图号正则、增强文件名解析、过滤构件编号 |
| 图名识别 | 1 | 普通说明文字容易被当成图名 | 加强图名关键词、说明文字过滤、提高长文本降权 |
| 专业判断 | 1 | 单靠图层或前缀时容易不稳 | 扩展专业前缀规则，结合文件名、图号和图层交叉判断 |
| CAD tag 映射 | 1 | 常见块属性 tag 有空格、下划线、大小写和中英文混写 | 扩充 tag 字典，增强 normalize_tag 覆盖面 |
| 文件名规则 | 1 | 真实项目文件名常混合图号、图名、版本、日期 | 增强文件名切分、图号识别和日期识别 |
| OCR / PDF 文本 | 1 | 扫描 PDF 可能空文本或低质量 OCR | 提示空文本 / 低可信，优先结合文件名和 OCR |
| 误判过滤 | 1 | 构件编号、轴号、说明文字可能误判为图号 / 图名 | 增强负例过滤与低可信提示 |
| 置信度 | 1 | 单一来源候选置信度过高或过低都不理想 | 调整来源权重，强化块属性优先级 |

## 三、优先优化项

| 优先级 | 优化项 | 原因 | 预期收益 |
|---|---|---|---|
| P1 | 图号 drawing_no 规则增强 | 真实项目中最常见且最影响检索与导出 | 提高图号命中率，减少人工补录 |
| P1 | 图名说明文字误判过滤 | 误把说明文字当图名会污染台账 | 降低错误图名和后续校核成本 |
| P1 | CAD block_attr tag 映射扩充 | 块属性是最可靠来源之一 | 提升 CAD 识别精度 |
| P1 | 专业判断前缀规则扩展 | 专业字段直接影响归类 | 提升台账专业准确率 |
| P2 | 文件名解析增强 | 真实项目常依赖文件名补强 | 提升无文本场景下的补充命中 |
| P2 | 低可信 issue 提示优化 | 低可信页需要更清楚的校核提示 | 提高校核效率 |
| P2 | OCR / PDF 空文本提示优化 | 扫描件和弱文本页需要明确引导 | 减少误操作 |
