## 三、修复问题

| 编号 | 问题 | 修复方式 | 测试结果 |
| -- | -- | ---- | ---- |
| 1 | 图号格式不全 | 扩展 `建施 / 结施 / 水施 / 电施 / 暖施 / A / S / E / M / P / T / JZ / JG / GS / DS / SS / NT` 规则 | 回归通过 |
| 2 | 构件编号误判图号 | 对 `KZ / KL / L / M / C / D / W / GZ / YBZ / CT / 门 / 窗 / 轴号` 增加过滤 | 回归通过 |
| 3 | 说明文字误判图名 | 增加说明文本黑名单与长文本降权 | 回归通过 |
| 4 | CAD tag 映射覆盖不足 | 扩充 drawing_no / drawing_name / version / issue_date / discipline tag 字典 | 回归通过 |
| 5 | 仅文件名来源过强 | 低可信与文件名来源 issue 改为提醒性质 | 回归通过 |
| 6 | PDF / OCR 空文本提示弱 | 空文本结果补充 issue 提示 | 回归通过 |
