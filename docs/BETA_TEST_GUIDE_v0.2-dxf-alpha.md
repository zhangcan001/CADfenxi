# v0.2-dxf-alpha 内测操作指南

## 一、内测目标

验证 PDF + DXF 图纸台账识别完整流程，重点观察 DXF 解析质量、候选值质量、字段融合结果、人工校核体验和 Excel 导出一致性。

## 二、推荐样本

建议准备：

- 5～30 个 DXF 文件
- 至少包含 1 个由 DWG 转换得到的 DXF
- 至少包含 1 个带标题栏块属性的 DXF
- 至少包含 1 个只有普通 TEXT / MTEXT 的 DXF
- 至少包含 1 个图层信息较完整的 DXF
- 至少包含 1 个无文字或文字较少的 DXF

## 三、测试流程

1. 新建项目
2. 上传 DXF
3. 准备 DXF 图纸页
4. 解析 DXF
5. 查看 CAD 解析摘要
6. 生成候选值
7. 生成推荐字段
8. 查看图纸台账
9. 人工校核
10. 导出 Excel
11. 检查 Excel 与页面台账是否一致

## 四、重点观察

- DXF 是否能正常解析
- TEXT / MTEXT 是否能提取
- ATTRIB 是否能提取
- 图层是否能提取
- 图号候选是否准确
- 图名候选是否准确
- 专业判断是否合理
- cad_block_attr 是否优先
- 普通说明文字是否被误判为图名
- 构件编号是否被误判为图号
- 人工确认字段是否会被重新融合覆盖
- Excel 导出是否与页面一致

## 五、问题分级

P0：主流程阻断、数据丢失、导出错误  
P1：人工确认被覆盖、状态错误、严重数据不一致  
P2：识别质量问题、候选值不稳定、部分 DXF 解析质量不足  
P3：体验优化、提示文案、布局细节
