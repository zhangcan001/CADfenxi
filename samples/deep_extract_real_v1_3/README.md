# v1.3 深度抽取回归样本说明

本目录用于放置 v1.3.3-fast-deep-extract-stable 阶段的深度抽取回归样本说明。

请勿提交真实涉密工程图纸、真实项目数据、业主信息或带有保密标识的 CAD / PDF 文件。

建议覆盖的样本类型：

1. 含 ACAD_TABLE 的 DXF。
2. 无 ACAD_TABLE、但由 TEXT / MTEXT 排列成表格的 DXF。
3. 含标题栏表格的 DXF。
4. 含材料表 / 设备表 / 图纸目录样式表格的 DXF。
5. 含大量 INSERT 块的 DXF。
6. 含图框块、标题栏块、图签块的 DXF。
7. 多张图纸图号重复的项目。
8. 多张图纸版本不一致的项目。
9. 多张图纸专业不一致的项目。
10. 异常 DXF / 空 DXF / 损坏 DXF。

自动化测试使用代码合成的脱敏 DXF 数据，不依赖真实图纸文件。
