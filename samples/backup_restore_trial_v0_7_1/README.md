# v0.7.1 备份恢复真实项目测试样本说明

本目录用于说明 v0.7.1 备份恢复真实项目测试的数据类型。

为避免提交真实涉密图纸，自动化测试使用代码生成的接近真实项目样本：

- PDF 项目：生成多页 PDF，执行拆页、裁剪、候选值、字段融合、人工确认、导出。
- DXF 项目：生成多个含标题栏文字/块属性的 DXF，执行解析、候选值、字段融合、人工确认、导出。
- DWG 转换项目：使用测试 DWG 字节和 mock 转换器生成 DXF，执行转换、解析、候选值、字段融合、导出。
- 混合项目：PDF + DXF + DWG，执行 CAD pipeline、人工确认和 Excel 导出。

真实或客户项目图纸请放在本地临时目录或 app_data 中，不要提交到仓库。
