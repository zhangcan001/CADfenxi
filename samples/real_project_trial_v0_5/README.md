# v0.5 真实项目试用样本目录

本目录用于本地放置 v0.5 真实项目试用资料，例如小型 PDF / DXF / DWG 图纸包。

建议样本范围：

- 10～50 张图纸。
- 覆盖建筑、结构、给排水、电气、暖通、消防等专业中的若干类。
- 同时包含规范文件名和不规范文件名。
- 尽量包含 CAD 导出 PDF、扫描型 PDF、标题栏块属性 DXF、普通 CAD 文字标题栏 DXF。
- 若有 DWG，请先确认可用外部 DWG 转 DXF 工具进行转换。

注意：

- 不要提交涉密真实图纸到 Git。
- `.gitignore` 已排除本目录下除 `README.md` 之外的文件。
- 真实测试完成后，请把统计结果和问题记录到 `docs/REAL_PROJECT_TRIAL_REPORT_v0.5.md` 与 `docs/REAL_PROJECT_TRIAL_ISSUES_v0.5.md`。
