# v0.8.4 CAD 预览稳定版样本说明

本目录用于放置 CAD 预览稳定版真实项目回归样本。

建议样本类型：

1. 普通 DXF。
2. 中文文字 DXF。
3. 多图层 DXF。
4. 含块 INSERT 的 DXF。
5. 含 TEXT / MTEXT 的 DXF。
6. 大坐标 DXF。
7. DWG 转换后的 DXF。
8. 异常或损坏 DXF。
9. 已执行 CAD pipeline 的项目。
10. 已备份恢复过的项目。

注意：

- 不提交涉密真实图纸。
- 真实图纸样本应由 `.gitignore` 排除。
- 可使用自动化测试生成的非涉密 DXF 作为基础验证样本。
