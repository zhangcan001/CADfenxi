# v0.3.3 CAD 批量处理手工样本目录

本目录用于本地放置 CAD 批量处理真实样本。不要提交涉密图纸或真实项目图纸。

建议准备：

- 10～30 个 DXF 文件。
- 5～20 个 DWG 文件。
- 中文文件名、空格文件名。
- 含块属性标题栏的 DXF / DWG。
- 只有普通 TEXT / MTEXT 的 DXF / DWG。
- 图层较多的 DXF / DWG。
- 无文字或文字较少的 DXF。
- 预期转换失败的 DWG。
- 预期解析失败的 DXF。

建议在包含中文和空格的本地路径中执行一次手工验证，例如：

```text
samples/manual_cad_batch_v0_3_3/中文 批量样本/
```

真实样本文件已在 `.gitignore` 中排除，仅保留本说明文件。
