# v0.3.1 DWG 手工冒烟样本目录

本目录用于本地手工放置 DWG 转 DXF 冒烟测试样本。

请不要提交涉密真实图纸。真实项目 DWG 建议仅保存在本机，并确保不会被提交到版本库。

建议样本覆盖：

- 普通 DWG
- 中文文件名 DWG
- 文件名包含空格的 DWG
- 中文目录下的 DWG
- 空格目录下的 DWG
- 不同 CAD 版本保存的 DWG
- 含标题栏块属性的 DWG
- 含 TEXT / MTEXT 的 DWG
- 含多图层的 DWG
- 损坏或预期转换失败的 DWG

推荐手工测试流程：

1. 启动后端和前端。
2. 新建项目：v0.3.1真实DWG转换测试。
3. 配置本机 ODA File Converter 或其他命令行转换工具路径。
4. 上传本目录或本机私有目录中的 DWG。
5. 执行单个转换和批量转换。
6. 对转换成功的 DWG 执行 DXF 解析、候选值生成、字段融合、人工校核和 Excel 导出。
